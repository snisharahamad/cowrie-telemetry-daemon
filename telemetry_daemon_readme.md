# Cowrie Telemetry Daemon

A Python daemon designed to monitor, parse, and route SSH/Telnet authentication logs generated by a Cowrie honeypot.

## 🏗️ Data Pipeline

1. **Log Generation:** Cowrie captures interactions and generates a JSON log file. 
2. **Parsing:** The daemon monitors the log file in real-time using non-blocking I/O.
3. **Data Routing:** Traces are archived locally in a SQLite database for analysis, and an HTTP POST request is triggered to a Discord Webhook for immediate notification.

## ✨ Features

* **Real-Time Parsing:** Continuous reading of `cowrie.json` via an end-of-file pointer (`os.SEEK_END`).
* **Relational Archiving:** Structuring log metadata (IP, credentials, timestamp) into SQLite.
* **Webhook Integration:** HTTP notifications sent to a specified endpoint.
* **Secrets Management:** `python-dotenv` isolates the Webhook URL from the source code.

## ⚙️ Deployment

### 1. Prerequisites
* Python 3.10+
* `uv` package manager (recommended)

### 2. Installation
```bash
git clone https://github.com/snisharahamad/sentinel-soar.git
cd sentinel-soar
uv venv
uv pip install python-dotenv requests
```

### 3. Configuration
Create a `.env` file at the root to store the Webhook URL:
```env
WEBHOOK_URL="https://discord.com/api/webhooks/YOUR_SECRET_LINK"
```

### 4. Startup
```bash
uv run sentinel_soar.py
```
